# Workflow Rules

## 1. Plan of Attack
- Always present a clear **plan of attack** before executing work or making code modifications in response to any user request.
- Outline the steps, files involved, and intended approach before proceeding with changes.

## 2. Step-by-Step Execution & Check-ins
- When a task is complex, break it down into sequential, manageable steps.
- Check in after completing each step to report progress and confirm before advancing to the next step.
